# Словарь Жизни

Приложение-генератор цитат по категориям с избранным и добавлением своих цитат.
Данные сохраняются между запусками в JSON-файлы.

## Версии
- minSdk: 26 (Android 8.0)
- targetSdk: 35 (Android 15)
- compileSdk: 35 (Android 15)
- Проверено на: Android 15 (API 35), эмулятор Pixel 5

## Экраны
- MainActivity — генератор цитат, 6 категорий, мысль дня
- FavoritesActivity — избранные цитаты с удалением
- AddQuoteActivity — добавление своей цитаты
