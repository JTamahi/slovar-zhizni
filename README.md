# Словарь Жизни

Приложение-генератор цитат по категориям с избранным и добавлением своих цитат. Данные сохраняются между запусками в JSON-файлы.

## Версии
- minSdk: 26 (Android 8.0)
- targetSdk: 35 (Android 15)
- compileSdk: 35 (Android 15)
- Проверено на: Android 15 (API 35), эмулятор Pixel 5

## Экраны приложения
В проекте реализовано 3 экрана (Activity):
- MainActivity — генератор цитат, 6 категорий (включая "Все" и "Мои цитаты"), функция "Мысль дня".
- FavoritesActivity — избранные цитаты с возможностью удаления.
- AddQuoteActivity — добавление своей цитаты с валидацией ввода.
